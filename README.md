# Hi, I'm eclipxia 👋

I build [RusherHack](https://rusherhack.org) plugins and themes for Minecraft, and I spend a lot of time tuning my Linux setup.

## Main projects

### RusherHack

- **[auto-raid](https://github.com/eclipxia/auto-raid)**: a RusherHack plugin that drinks an Ominous Bottle when the raid victory boss bar appears, so you can chain raids on a raid farm hands-free. Supports 1.21.4 and 1.21.11. *(Java)*
- **[Celestial Theme](https://github.com/eclipxia/CelestialTheme1.21.11RH)**: a Celestial-style ClickGUI theme for RusherHack, with periwinkle panels, adjustable scale and full color control. Supports 1.21.4, 1.21.11 and 26.2. *(Java)*

### Linux setup

- **[dotfiles](https://github.com/eclipxia/dotfiles)**: my general config.
- **[nvim](https://github.com/eclipxia/nvim)**: Neovim config. *(Lua)*
- **[dwm](https://github.com/eclipxia/dwm)**: my build of the dwm window manager. *(C)*
- **[sway](https://github.com/eclipxia/sway)** and **[waybar](https://github.com/eclipxia/waybar)**: Wayland desktop config. *(Nix, CSS)*
